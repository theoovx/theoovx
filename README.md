## 👋 Tentang Saya

Saya lulusan **Teknik Instalasi Tenaga Listrik (TITL)** yang terbiasa bekerja langsung di lapangan: instalasi, troubleshooting, dan perawatan sistem kelistrikan. Dari situ saya tertarik menggabungkan dunia listrik dengan **kode**: membuat sistem monitoring, perangkat IoT, dan web yang berguna.

Saya masih terus belajar, dan repo-repo di sini adalah catatan prosesnya.
